# RESEARCH — 미륵 장전 매크로 레짐(RISK_ON/OFF)의 실제 적중률 v1

_작성: 2026-09-06 [MW0601]. 실행체 `scripts/mireuk_macro_regime_hitrate.py`. 데이터: 미륵 `logs/*.log`의
`[Regime]` 줄(실제 판정), `raw_data.db::raw_features`(재구성), `raw_candles`(실현값)._

**한 줄 결론: 검증할 수 있는 표본은 라이브 40일(로그로 확인되는 것은 21일)이고, 그 안에서 RISK_OFF는
한 번도 나오지 않았다. RISK_ON은 방향(시가→종가 상승)을 기저율보다 못 맞히고(35~50% vs 44~55%),
변동성 분위(조용/중간/시끄러움)도 기저율과 구분되지 않는다(조용 47% vs 44%). 신호가 있는 것은
레짐이 아니라 그 입력인 VIX 수준(실현 범위와 순위상관 +0.45)인데, 분류기가 ON/NEUTRAL 둘로
뭉개면서 그 정보를 버린다.**

## 1. 미륵의 레짐 정의와 실제 산출 기록

`collection/macro/regime_classifier.py`: 점수 = VIX(<15 +2 / <20 +1 / >25 −1 / >30 −2) + S&P500
야간 등락(>+0.5% +1 / <−0.5% −1) + USD/KRW(>+0.5% −1 / <−0.5% +1). ≥+2 RISK_ON, ≤−2 RISK_OFF.
장전 08:58 1회 판정(`main._pre_market_stage2`). 나스닥·US10Y는 인자로 받되 점수에 안 들어간다.

| 원천 | 일수 | 분포 |
|---|---|---|
| A. 로그 `[Regime]` (2026-08-05~09-04) | 21 | RISK_ON 10 · NEUTRAL 11 · **RISK_OFF 0** |
| B. 재구성 — 매크로 라이브 수집일(`quality_macro_available=1`) | 40 | RISK_ON 17 · NEUTRAL 23 · **RISK_OFF 0** |
| C. 재구성 — 전체 | 248 | 208일은 09:00 VIX·SP500이 **전일과 동일**(백필 정지) — 예측이 아님 |

재구성은 저장된 정규화값(`macro_vix=(VIX−15)/25`, `_CHG_CLIP=0.03`)을 역변환해 같은 규칙을 적용한
것으로, 로그와 **20/21 일치**(08-11: 로그 VIX 14.9 → 저장값 15.0 반올림으로 경계가 갈림).

**RISK_OFF가 0회인 이유**: 검증 구간에 KOSPI200이 하루 10% 넘게 움직인 날(07/30~08/04)이 있었는데
그때 VIX는 15~17이었다. 미국 공포지수는 한국 선물의 변동성을 설명하지 않았다.

## 2. 방향 적중 — RISK_ON이면 오르는가

| 표본 | 레짐 | n | 시가→종가 상승 | 95% CI | 전일→종가 상승 | 평균 시→종 | 평균 갭 |
|---|---|---|---|---|---|---|---|
| A 로그 | RISK_ON | 10 | 50% | 24~76 | 70% | +0.15% | +1.08% |
| | NEUTRAL | 10 | 60% | 31~83 | 70% | −0.00% | +0.11% |
| | 기저율 | 20 | 55% | | 70% | | |
| B 라이브 | RISK_ON | 17 | **35%** | 17~59 | 65% | **−0.39%** | **+1.25%** |
| | NEUTRAL | 22 | 50% | 31~69 | 59% | −0.37% | −0.34% |
| | 기저율 | 39 | 44% | | 62% | | |
| 대조 | 나스닥 야간 부호 그대로 | 25 | 52% | | 56% | | |

- RISK_ON 날은 평균 **+1.25% 갭업으로 열리고 시가에서 종가까지 −0.39%** 다. 야간 낙관은 갭에 이미
  들어 있고 장중은 되돌린다. 「전일→종가 65%」는 갭이 만든 수치라 장중 매매에는 쓸 수 없다.
- 시가→종가 방향 적중은 어느 표본에서도 기저율을 못 넘고, 나스닥 부호 하나(52%)와도 차이가 없다.
  CI 폭(±20%p)이 말하듯 **표본이 결론을 낼 크기가 아니다** — 다만 우위의 흔적은 없다.

## 3. 변동성 적중 — RISK_ON이면 조용한가 (분위 경계 = 직전 60세션, 예측 시점에 아는 값)

| 표본 | 레짐 | n | 조용 | 중간 | 시끄러움 | 평균 범위 |
|---|---|---|---|---|---|---|
| A 로그 | RISK_ON | 10 | 80% | 20% | 0% | 3.38% |
| | NEUTRAL | 10 | 60% | 30% | 10% | 3.86% |
| | 기저율 | 20 | 70% | 25% | 5% | 3.62% |
| B 라이브 | RISK_ON | 17 | **41%** | 41% | 18% | 5.22% |
| | NEUTRAL | 22 | 45% | 27% | 27% | 4.61% |
| | 기저율 | 39 | **44%** | 33% | 23% | 4.87% |
| | RISK_OFF | 0 | 판정된 날 없음 — **시끄러움 예측은 검증 자체가 불가** | | | |

- RISK_ON → 조용 41% vs 기저 44%, 시끄러움 18% vs 23%: **차이가 표본 오차 안**이다(n=17). 조용 비율은
  기저율보다 오히려 낮고, 평균 범위(5.22%)는 NEUTRAL(4.61%)보다 크다 — 「RISK_ON = 조용」이 아니다.
- 같은 39일에서 §7.9의 「전일 범위 분위 그대로」는 3분류 44%(무정보 33%) — 레짐보다 낫다.
- **연속값 순위상관(라이브 39일, vs 실현 범위)**: 매크로 점수 **−0.19**, VIX **+0.45**, |SP500| +0.02.
  VIX 수준은 변동성과 실제로 상관이 있는데, 점수로 합산하고 ON/NEUTRAL로 이산화하면 −0.19로
  사라진다. 로그 21일에서는 점수 −0.33, |SP500| −0.47(부호가 「S&P가 크게 움직인 다음 날이 조용」).
- 전체 248일의 상관(+0.58)은 백필 구간에서 매크로가 얼어 있어 **국면 간 차이가 섞인 값**이다. 쓰지 않는다.

## 5. 판정

1. **RISK_OFF는 검증 불가**(0회). 레짐은 이 데이터에서 사실상 ON/NEUTRAL 이진이고, 그 이진은
   방향·변동성 어느 쪽도 기저율과 구분되지 않는다.
2. 원인은 설계다 — 미국 야간 지표로 한국 선물의 **장중** 성격을 가리키려 하는데, 야간 정보는 갭에
   흡수된다(RISK_ON 갭 +1.25%). 남는 장중은 오히려 되돌림이다.
3. 살릴 것은 VIX 수준(순위상관 +0.45)뿐이고, 그것도 §7.9의 「전일 범위」(같은 표본 44%)보다 못하다.
   미륵 피처가 되돌림·변동성 어느 모델에서도 도움이 안 됐던 것(§7.4·§7.9)과 같은 결론이다.
4. 표본 40일·CI ±20%p — 「우위가 없다」는 것이지 「해롭다」까지는 못 말한다. 다만 §4의 방향은 나쁘다.

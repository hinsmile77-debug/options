_작성: 2026-09-06 [MW0601]. 선행 문서(`RESEARCH_PREMARKET_LEVELS_v1`, `_WFA_v1`)의 「구조 레벨은

**한 줄 결론: 규칙은 「고점 = 시가 + 0.27·ATR14, 저점 = 시가 − 0.41·ATR14」(09/03 마감 기준 60세션
중앙값)처럼 단순한 것이 가장 낫고, 점추정 오차는 MAE 14.5pt(시가의 1.39%, 0.30 ATR)다. 신뢰구간은

## 0. 정의

| 기호 | 뜻 |
|---|---|
| O | 당일 08:45 시가 (예측 시점에 안다) |
| H, L | 당일 일중 고가·저가 = 상→하 되돌림 고점, 하→상 되돌림 저점 |
| ATR14 | 전일까지 14세션 평균 진폭 |
| u, d | (H − O)/ATR14, (O − L)/ATR14 — 예측 대상 |

예측은 **전날까지의 봉 + 당일 시가**만으로 한다(08:50 게시자와 같은 조건). 신뢰도는 훈련창 잔차의
25/75·10/90 분위로 만든 **50%·80% 구간**이 검증일에 실제 H·L을 담는 비율(coverage)이다.

## 4. 해석 — 이 예측의 성격

1. **거리에는 정보가 있고, 위치에는 없다.** 극값까지의 거리는 변동성으로 0.30 ATR 오차 안에 예측되지만, 그 거리를 어느 구조적 가격에 붙이려는 시도(M4)는 오차를 늘린다. 선행 문서 §5.5의 「구조 레벨은 무작위와 같다」와 같은 사실의 다른 면이다.
2. **예측은 「기대 진폭」이지 「반환점 지목」이 아니다.** 09/04의 1063이 맞은 것은 진폭 예측(1057)이 ATR의 1/6 안에 든 것이지, 1063이라는 자리를 안 것이 아니다. 08/04(시가가 고점)·09/03(14:15 급락) 같은 날은 어느 모델도 못 맞히고, 그것이 80% 구간 밖 20%의 정체다.
3. **신뢰도는 구간으로 말해야 한다.** 점추정만 주면 ±0.5% 적중 25%다. 「고점 1057 ± 11pt(50%) / ± 23pt(80%)」가 정직한 표현이다.

## 5. 운용 규칙 (제안)

- 08:20: 전일까지 봉으로 ATR14와 60세션 중앙값 u·d를 계산해 둔다. 08:45 시가 확정 즉시 고점·저점과 두 구간을 낸다(계산 1초).
- 산출물 형식: `고점 1057 (50% 1051~1067 · 80% 1048~1072) / 저점 1028 (50% 1017~1036 · 80% 1007~1043)`.
- 변동성 분위(ATR/시가)를 같이 적는다 — 낮음이면 오차 기대 10pt, 높음이면 20pt.
- **쓰지 않을 것**: 전일 고저 참조(N0), 구조 레벨 스냅(M4), 60세션 미만 표본의 회귀(M3·M5).

### 7.4 판정

1. **09:30 재예측은 1단계를 분명히 개선한다** — MAE 14.2 → 11.0pt, ±0.5% 적중 25 → 44%. 10:00이면 9.8pt·48%. 시간이 갈수록 좋아지는 것은 그날 경로를 더 많이 알기 때문이다.
2. **개선은 전부 경로에서 온다.** 미륵 피처는 10개(P2)·3개(P3)를 넣으면 나빠지고, 1개(P4·P5)를 넣으면 계수가 0에 수렴해 P1과 같아진다. 「피처가 나쁜가, 개수가 나쁜가」의 답은 **둘 다** — 하나만 넣어도 정보가 없고, 여럿 넣으면 60세션에서 잡음을 학습한다.
3. 구간은 2단계에서 약간 과신한다(80% 구간이 73~75%). 잔차를 훈련창 안에서 계산해 생기는 낙관이다. 실제 운용에서는 80% 구간 폭을 ×1.1 해서 쓰는 것이 정직하다.
4. **채택: T = 09:30, 모델 P1.** 09:05는 개선이 작고(13.2), 10:00은 하루의 1/5가 지난 뒤라 「예측」의 의미가 줄어든다. 09:30은 사용자가 제안한 시각이기도 하고 검증에서도 타당하다.

### 7.6 운용 규칙 (2단계 포함)

- 08:45: 1단계 M1 — 고점 = 시가 + med(u)·ATR, 저점 = 시가 − med(d)·ATR, 50%·80% 구간.

### 10.5 [2026-09-06 추가] R̂ 스케일링 채택 — 손익 조사와 반영

§7.9의 「예측 R̂ ÷ 훈련 중앙 R」로 구간 폭을 재배분하는 방식에 **하한**을 두고 다시 쟀다(144세션, 09:30 P1 기준).

| 하한 | 08:45 커버리지 / 폭 | 09:30 커버리지 / 폭 | 사전(ATR14) 분위 조/중/시 (09:30) | 실현 분위 조/중/시 (09:30) |
|---|---|---|---|---|
| 없음(기본 구간) | 78% / 4.68% | 74% / 3.09% | 64 / 78 / 80 | 93 / 79 / 59 |
| 0 | 79% / 4.78% | 77% / 3.05% | 65 / 79 / 89 | 85 / 74 / 75 |
| **0.85** | **83% / 4.82%** | **81% / 3.07%** | 71 / 83 / 90 | 93 / 80 / 75 |
| 1.0 (넓히기만) | 85% / 5.21% | 83% / 3.37% | 74 / 86 / 90 | 96 / 84 / 76 |

**판정: 하한 0.85 채택.** 폭이 거의 그대로(08:45 +3%, 09:30 −1%)인데 커버리지가 명목 80%에 닿고(83 / 81%),
시끄러운 날 과소신(59%)이 75%로, 조용한 날 과신(64%)이 71%로 좁혀진다. 하한 1.0은 폭이 9~11% 넓어져
「넓혀서 맞춘 것」이다. 상한 2.0은 검증에서 닿은 적 없는 안전 장치다.

배지 반영: 08:50은 확정분 회귀(V1), 09:30은 확정분 + 경로 회귀(V2)로 log R̂을 내고, 구간의 잔차 분위에
R̂/중앙R(하한 0.85, 상한 2.0)을 곱한다. 카드에 「R̂×0.85」처럼 배수를 적고, 파일에는 스케일 전 구간(`raw`)을
같이 남겨 **장후 채점이 두 구간을 나란히 센다** — 채택의 손익을 누적으로 추적하는 자리다.

09/04 재현에서 두 단계 모두 R̂×0.85(하한) — 09/04는 창 최소 변동성 날이라 R̂이 조용을 예측했고 하한이 과축소를
막았다. 08:50 저점 80% 구간이 1000~1041 → 1004~1038로 좁아졌고 실제 저점 1042.3은 둘 다 밖이었다.

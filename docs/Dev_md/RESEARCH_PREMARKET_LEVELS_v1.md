## 3. 체계 — 마흐디 장전 맥점 산출

### 3.1 원칙

1. **전일까지의 데이터만** 쓴다. 당일 시가(08:45)는 상·하 분기 기준으로만 쓰고 레벨 값 자체에는
   넣지 않는다 — 08:20에 낸 수와 08:50에 낸 수가 값은 같고 「어느 쪽이 상방인가」만 다르다.
2. **레벨마다 근거를 붙인다.** 근거 없는 수는 내지 않는다(규약 C — 지어내지 않는다). 같은 자리를
   가리키는 근거 수가 **합류도**이고, 그것이 유일한 우선순위다.
3. **판단하지 않는다.** 산출물은 후보 목록이다. 신호 계층·진입·청산 어디에도 연결하지 않는다
   (§5 검증 통과 전).

### 3.2 입력

| 원천 | 테이블 | 시각 | 비고 |
|---|---|---|---|
| 선물 1분봉(과거 6세션) | `market_raw_1m` (`active_futures_symbol`) | 전일 15:34까지 | 마감 동시호가(15:35~45)는 없다 — 공식 종가·고저와 소차(09/03 1030.45 vs 1030.00) |
| 옵션 마감 체인 OI | `option_analysis_1m` 전일 15:00~15:45 마지막 스냅샷 | 전일 | ATM±2 창만 수집되므로 먼 행사가의 벽은 못 본다 |

### 3.3 계산 (`scripts/premarket_levels.py` 그대로)

| 단계 | 규칙 | 파라미터 |
|---|---|---|
| (a) 매물대 | 과거 6세션 1분봉이 **지나간 분 수**를 0.5pt bin에 누적 → 3-bin 평활 → ±2pt 창에서 최대이고 60분 이상인 bin | `LOOKBACK=6, BIN=0.5, PEAK_WINDOW=2.0, PEAK_MIN_MINUTES=60` |
| (b) 갭 가장자리 | 연속 두 세션의 고저 범위가 안 겹치면 그 구간의 양 끝 | — |
| (c) 전일 고·저, 전일 VWAP, 4세션 VWAP | 그대로 | — |
| (d) 옵션 OI 행사가 | 전일 마감 체인 만기 합산 OI 상위 3 | `top_n=3` |
| 병합 | 정수 반올림 후 1.5pt 안의 후보를 한 레벨로(근거 목록 합침) | `MERGE_PT=1.5` |
| 선택 | 기준가(전일종가, 08:50 이후엔 시가) 위로 가까운 3개 = 상방 1·2·3차, 아래로 3개 = 하방 | `pick(n=3)` |

**왜 거래량이 아니라 체류 분인가**: `features/volume.py::volume_profile()`은 거래량 기준 POC/VAH/VAL을
이미 낸다. 그런데 1분봉 거래량은 08:45·15:30 부근에 몰려 히스토그램이 개장·마감 가격으로 쏠리고,
사람이 차트에서 「선반」으로 읽는 것은 **가격이 머문 시간**이다(§1.2의 76분·49분·43분). 둘은
다른 질문이라 나란히 두되 장전 레벨은 체류 분을 쓴다.

### 3.4 시각과 자리

- **08:20** — v6 §16.1 「감마 지형 사전 계산 … 전일 POC/VAH/VAL → 시나리오 카드」와 같은 슬롯. 전일 데이터만으로 상·하 3개씩(기준 = 전일종가).
- **08:50** — 시가 확정 후 `--ref open`으로 재분기. 값은 그대로, 상·하만 갈린다(09/04가 정확히 이 경우 — 갭업 13.9로 전일종가 기준 「하방」이던 1042·1040이 시가 기준으로는 바로 아래 지지가 됐다).
- 출력 자리(제안 순서): ① 콘솔(지금), ② 일일점검 산출물의 새 절 「장전 맥점」(P1), ③ COCKPIT Gamma Map 수평선(P2), ④ Structure Stop(§13.3) 후보(P2 이후).

### 3.5 기존 코드 접점

| 기존 | 관계 |
|---|---|
| `features/volume.py::volume_profile` | 거래량 POC/VAH/VAL — 체류 분 매물대와 **병기** 대상 |
| `features/options_intel.py::gamma_walls` | 감마 노출 상위 행사가 — (d)의 OI 행사가와 다른 축(감마×OI). 둘이 같은 행사가를 가리키면 합류도 +1로 셀 수 있다(미구현) |

### 3.6 하지 않을 것

- 신호 계층(`fusion/`)·진입(`execution/entry.py`)에 연결하지 않는다.
- DB에 적재하지 않는다(P1에서 산출물 파일로만 남긴다).

- 1049·1057 재현(1048·1057). 1052는 게시자가 내지 않은 레벨인데 09:05 고가 1051.65에서 실제로 반락했다.

P1에서 「선택 단계의 구역 병합 폭(≈4pt)」을 두거나 4개를 보여 주는 것으로 고칠 후보. 매물대 규칙이 봉우리 중심(1063.5)을 잡고 사람은 가격 쪽 가장자리(1062~1063)를 읽는 차이도 같이 다룬다.

### 4.2 지표 A — 「터치 후 30분 내 3pt 반응」은 변별력이 없다

| 레벨 집합 | 터치(±1pt) | 터치 후 반응 |
|---|---|---|
| 실제 산출(시가 기준 상·하 3개, 9세션 50개) | 80% | 68% |
| **무작위** — 같은 거리 분포를 날짜 간 셔플, 200회 중앙값 | 78% (90%구간 72~84) | 66% (58~74) |
| 시가 ±3/6/9pt 등간격 | 91% | 83% |

실제와 무작위가 같다. 등간격이 더 좋은 것은 단순히 시가에 가깝기 때문이다. **이 지표는 일중
변동성을 재는 것이지 레벨을 재는 것이 아니다** — 09/04 텍스트 파일의 답변이 말하는 「반환점」과
무관하다. 폐기.

### 4.3 지표 B — 「일중 고가·저가가 예측 레벨 ±1.5pt에 안착」

09/04의 1063.85가 바로 이 사건이다.

| | 안착 |
|---|---|
| 실제 산출 | **8 / 18** (9세션 × 고·저) |
| 무작위(거리 셔플 2000회) 중앙값 | 5 / 18 (95% 상한 7) |
| p(무작위 ≥ 실제) | **0.04** |

n=9라 **시사적일 뿐 결론이 아니다.** 5pt 스윙 극값 안착도 재려 했으나 지그재그 구현이 틀려
(09/04 스윙 0개로 잡힘) 수치를 싣지 않는다 — P1에서 다시 짠다.

### 4.4 [2026-09-06 추가] 26주 WFA 결과 — `RESEARCH_PREMARKET_LEVELS_WFA_v1.md`

미륵(futures) DB 249세션으로 §5 프로토콜을 실행했다. **사전 등록 정의(±0.15%)로 WFA 30%(1주)·16%(9주),
무작위 30%·14% — 구분 안 됨.** 60%는 정의를 넓혀야만 나오고 그때는 무작위가 더 높다. 원인은
검증창의 일중 범위 중앙값이 시가의 5.2%라는 시장 특성이다. 상세·다음 단계는 그 문서 §6.

**§4.2의 「터치」 지표는 폐기가 아니라 무효다**(그 문서 §5.5.1). 일중 경로가 연속이라 레벨이 그날

직접 재면 체류·되돌림·정지 모두 우위가 없고 **조용한 날의 극값 근접도만** 무작위를 넘는다.

=== 2026-09-07  기준 전일종가 1053.05  (원천 세션 08/28~09/04, 후보 12개)

  상방3차  1060  합류1  근거=[OI행사가1060(833)]
  하방1차  1052  합류2  근거=[전일VWAP1051.9, 갭하변09/02고1052.6]
  하방2차  1050  합류1  근거=[OI행사가1050(5741)]
  하방3차  1048  합류2  근거=[매물대1048.0(518분/4세션), 4세션VWAP1049.1]
